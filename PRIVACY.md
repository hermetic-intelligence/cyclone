# Cyclone DSA Capture privacy policy

Last updated: 2 October 2026

Cyclone records a LeetCode practice attempt only when you start a recording. It reads the current problem URL and statement, the visible code editor, and observed Run and Submit actions and results. It also records your microphone audio while a session is active. These details may contain information you choose to type or say.

Cyclone keeps the recording and events in your browser while the session is being captured and processed. It saves a raw session ZIP and a report ZIP to your computer through Chrome Downloads. After you agree in the popup, Cyclone sends audio passages and the problem title through its authenticated server to OpenAI GPT-Transcribe to generate a speech transcript. Speech timing in reports describes approximate audio-passage intervals, not individual words. With your agreement in the extension popup, Cyclone automatically uploads each completed report ZIP to private Supabase storage so the developer can review practice attempts and improve Cyclone. The full raw ZIP is not uploaded, but microphone audio passages are transmitted for transcription. Uploads use an anonymous account tied to this browser installation. Other users cannot read your report through the app. The developer can read stored reports and completed passage transcripts. If upload fails, the report remains in browser storage and Cyclone retries; you can see the pending state in the popup. After both downloads complete, Cyclone deletes its temporary raw session copy from browser storage. Downloaded ZIP files remain until you delete them.

Cyclone does not download speech models. Cyclone’s server forwards audio passages to OpenAI without storing audio in Supabase. It stores each completed passage’s text and an allowance reservation in a private database to avoid duplicate paid requests. Network requests expose connection information such as your IP address to Supabase. OpenAI receives requests from Cyclone’s server. OpenAI’s API data handling applies to the audio and context sent for transcription; see https://developers.openai.com/api/docs/guides/your-data. Cyclone sends the report ZIP, including code, problem content, and transcript, to Supabase for storage. It sends microphone audio passages to OpenAI through its server, but does not upload the raw recording ZIP. The extension has no analytics, advertising, or coaching model. If you share a report with your own model or another person, that sharing is under your control and subject to their privacy practices.

You can remove model files left by older local builds using **Remove old model downloads** in the popup. This does not remove recordings or reports. You can stop recording in the extension, delete the ZIP files from your Downloads folder, remove Cyclone's temporary browser data by removing the extension from Chrome, and revoke Cyclone's microphone access in Chrome's site settings. Removing the extension does not delete reports already uploaded to Supabase. To request deletion of an uploaded report and its cached passage transcripts, email the privacy contact below with the session ID from its report ZIP.

Cyclone uses the recording and page details to create your report and help the developer evaluate the product. It does not sell the data or use it for advertising.

The extension does not provide a self-service control to delete an uploaded report or set a retention period. Contact the privacy address below to request deletion of an uploaded report. The current friends test has no published automatic deletion schedule; the developer should confirm deletion requests against the stored report and its session ID.
